Spec-Driven Docs

A documentation-first governance system for AI-assisted and human-led software projects, organized around identity, manifesto, architecture, roadmap, changelog, design contract, feature inventory, and QA records.

  1. Read the project identity.
  2. Anchor work in the development manifesto.
  3. Use architecture and roadmap docs as source of truth.
  4. Keep features, checklists, research, plans, audits, and human QA organized.
