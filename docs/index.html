Spec-Driven Docs

Templates and agent skills you add to your own repository, so that every AI agent and human working in it starts with the same context and follows the same procedures.

  1. Copy the template set into your repository, or have your coding agent run the setup skill.
  2. Write down what the project is, its hard constraints, its architecture, and its direction.
  3. Agents load the same context every session, and stop to ask when a request conflicts with a rule.
  4. Approved exceptions are recorded as decisions; structural changes start as short proposals.
